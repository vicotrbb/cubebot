# Shared components

`Cube` is the agent avatar (paint, eyes, accessory; mood from activity). `primitives` holds Dialog, Field, Alert, Status, Skeleton, Empty and `when`. Tokens live in `src/styles/tokens.css` (light and dark), base styles in `base.css`, controls (`.btn`, `.field`, `.chip`, `.table`, `.tabs`) in `controls.css`. Keep feature-specific components with their feature.
