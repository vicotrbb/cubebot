# Meetings: implementation plan

Spec: docs/superpowers/specs/2026-11-15-meetings-design.md. Each task ends with its tests passing, `just lint` clean and a commit.

## Module layout

- `apps/orchestrator/src/meetings/`: `mod.rs` (the `Meetings` handle, records, create, read, update, invite, link), `settings.rs`, `invitations.rs` (email), `calendar.rs` (the Calendar source), `public.rs` (token lookup and the rate limiter), `live/` (the in-memory rooms: `wire.rs` framing, `room.rs` relay and roster, `hearing.rs`, `floor.rs`, `voices.rs`, `screens.rs`), `summary.rs`.
- `apps/orchestrator/src/api/meetings.rs` (members) and `apps/orchestrator/src/api/public.rs` (guests, no cookie read).
- `apps/orchestrator/src/work/`: `chat_turns.meeting_id` and `talk_only`, the Meeting message in history and the event stream (as `calls.rs` does), the meeting instruction at claim.
- `modules/protocol`: `Turn.talk_only`, `Turn.meeting`.
- `apps/agent`: no tools under `talk_only`; the `meeting_screen` tool.
- `apps/web/src/features/meetings/`: data hooks, the New meeting sheet, the Meetings page, the green room, the room, the media engine (`media/`), the settings page; `routes/_app.meetings.*`, `routes/m.$token.tsx`, `routes/_app.platform.meetings.tsx`.
- `deploy/chart`: `templates/meetings-ingress.yaml`, `templates/meetings-httproute.yaml`, values, README.

## HTTP contract

| Method and path                                      | Who                                | Does                                                                                                                                                             |
| ---------------------------------------------------- | ---------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/meetings`                                  | member                             | meetings the caller owns or is invited to: live, upcoming, and the last 50 ended                                                                                 |
| `POST /api/meetings`                                 | member                             | create; no `starts_at` means instant. Body: title, description, starts_at, ends_at, open_join, agent_mode, invite `{accounts, agents, emails}`, email_connection |
| `GET /api/meetings/{id}`                             | participant                        | the meeting, its link (participants only), invitations with email status, attendance, transcript and summary                                                     |
| `PATCH /api/meetings/{id}`                           | owner                              | title, description, schedule, open_join, agent_mode, locked                                                                                                      |
| `DELETE /api/meetings/{id}`                          | owner                              | cancel a meeting that is not live                                                                                                                                |
| `POST /api/meetings/{id}/invitations`                | participant                        | add people, agents, emails during or before the meeting; optional email_connection                                                                               |
| `DELETE /api/meetings/{id}/invitations/{invitation}` | owner                              | remove an invitation                                                                                                                                             |
| `POST /api/meetings/{id}/link`                       | owner                              | `{enabled}`: a new token, or none                                                                                                                                |
| `GET /api/meetings/email-connections`                | member                             | the caller's own connections offering a send tool                                                                                                                |
| `GET`, `PUT /api/meetings/settings`                  | member reads, administrator writes | the installation settings                                                                                                                                        |
| `GET /api/meetings/{id}/live` (WebSocket)            | participant                        | the room                                                                                                                                                         |
| `GET /api/public/meetings/{token}`                   | anyone                             | title, host name, state, lobby                                                                                                                                   |
| `GET /api/public/meetings/{token}/live` (WebSocket)  | anyone with the link               | the room as a guest                                                                                                                                              |

"Participant" means the owner or an invited member. Agents need `conversation.send` for the inviter.

## Wire protocol (binding for server and console)

One WebSocket per participant. All integers little-endian.

### Binary, browser to server

| first byte     | rest                                                           |
| -------------- | -------------------------------------------------------------- |
| `1` microphone | PCM16 mono at 16 kHz (100 ms frames, as calls)                 |
| `2` camera     | flags u8 (bit 0: key frame), timestamp u32 (ms), encoded chunk |
| `3` screen     | same as camera                                                 |

### Binary, server to browser

| first byte | rest                                                                                |
| ---------- | ----------------------------------------------------------------------------------- |
| `1` audio  | source u16, sample rate u32, PCM16 mono (people at 16000, agents at their TTS rate) |
| `2` camera | source u16, flags u8, timestamp u32, chunk                                          |
| `3` screen | source u16, flags u8, timestamp u32, chunk                                          |

`source` is the sender's slot, a small number unique within the room's life, never reused.

### Text, server to browser (`kind` field)

- `waiting`: a guest is in the lobby. `{kind}`
- `welcome`: admitted. `{kind, you: slot, title, host: bool, member: bool, open_join, locked, captions: bool}`
- `roster`: the whole roster on every change. `{kind, participants: [{slot, kind: "person"|"guest"|"agent", name, account?: uuid (members only), agent?: uuid (members only), avatar?: Avatar (agents), host, mic, camera, screen, hand, can_present?: bool (agents: the viewer may ask it to share)}]}`; an agent's `screen` is true while it shares its desktop
- `track`: `{kind, source, stream: "camera"|"screen", codec: string|null, width, height}`; replayed to newcomers; `codec: null` means the stream stopped.
- `keyframe`: to a sender. `{kind, stream}`
- `caption`: `{kind, source, id, text, final: bool}`; `id` is stable per utterance so a partial is replaced by its final.
- `agent`: `{kind, source, state: "listening"|"thinking"|"speaking"}`
- `interrupt`: `{kind, source}`: drop that agent's queued audio.
- `desktop`: `{kind, source, tiles?: [{x, y, png}], ended?: true}`; the first message after a share starts or after anyone joins holds every tile; the canvas is 1280x800.
- `lobby`: to signed-in members. `{kind, waiting: [{id, name}]}`
- `meeting`: `{kind, locked, open_join}`
- `preparing`: speech models downloading. `{kind, model, received, total}`
- `notice`: `{kind, text}`
- `denied`, `removed`, `ended`: `{kind}`, then the server closes.

### Text, browser to server

- `hello`: first frame, required. `{kind, name?}`; `name` is required for guests (1 to 40 characters after trimming).
- `state`: `{kind, mic, camera, screen, hand}`
- `track`: `{kind, stream, codec: string|null, width, height}`
- `want_keyframe`: `{kind, source, stream}`
- `admit`, `deny`: `{kind, id}` (signed-in members)
- `remove`: `{kind, source}` (host)
- `lock`: `{kind, locked}` (host)
- `present`: `{kind, source, share: bool}` asks an agent to share or stop sharing its screen (participants allowed to view that agent's desktop)
- `end`: `{kind}` (host) ends the meeting for everyone
- `ping`: `{kind}` every 10 s; the server drops a socket silent for 15 s.
